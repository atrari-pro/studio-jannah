# UseCase Author

Rôle : raconter un **cas complexe de mesure** (cross-domain, iframe, réconciliation…).

## Structure obligatoire
1. Contexte (marque fictive OK + secteur)
2. Parcours utilisateur (ex. site → paiement tiers → retour)
3. Ce que l’analytics **croit** voir vs réalité
4. Leviers : iframe / S2S / postMessage / réconciliation CRM
5. Limites (consent, IT, PSP)
6. Ce que Studio Jannah apporte

## v1
Narratif + schéma mermaid/ascii — **pas** de fausse page paiement hors domaine.

## Output
`content/use-cases/<slug>.md` (draft) + notes pour Measurement (events suggérés).
